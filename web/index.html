Neurosity Crown · local-first

Your focus log

Record a session, keep the file, read it back. This is the beginning of a way to hold your own Crown data instead of leaving it in a console you cannot query.

Your data stays on this device. Sessions are saved in this browser's own storage. There is no account, no server, and no upload. Nobody else can read them, including the person who built this. Clearing your browser data deletes them, so export a copy of anything you want to keep.

Heads up. Anything you record now will be lost when you close this tab, so export it before you leave.
Real data · needs the headset

Record from your Crown

The recorder that talks to the headset runs on your computer, not in this page. That keeps your Neurosity login out of any website, including this one. Run it, then bring the file back here.

git clone https://github.com/samanthalin130/crown-focus-logger.git cd crown-focus-logger npm install cp .env.example .env # then put your Neurosity email and password in it npm run live # Ctrl+C to stop

That writes focus-log.csv next to the project. Import it below.

Your log

Everything you have recorded or imported, held in this browser. Export any session as CSV to open it in Excel, Numbers or Sheets, or export the whole log as a backup file you can import on another device.

Crown Focus Logger. Focus and calm are scores produced by Neurosity's models, not physical measurements, and they are not comparable between people or between sittings. Everything on this page is computed in your browser from your own file.
